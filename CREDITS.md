# Sky image sources (art/skies/)

All skies here are CC0 / public domain. Each folder holds `pano.png`, a 2:1
equirectangular panorama in the format `tools/sky.py` imports for the
"texture" sky style. "Animated" = the plugin/build drifts the panorama
horizontally (frames = the pano rolled by W/N pixels, loops exactly).
